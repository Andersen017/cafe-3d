# Кафе / проект в 3D

Интерактивная модель здания, входного навеса, террасы и оборудования. Архитектура, конструкции и инженерные подключения управляются отдельными слоями. Модель дополняется по мере проектирования; ссылка на просмотр остаётся постоянной.

**Просмотр:** https://Andersen017.github.io/cafe-3d/

Первая версия: **R01, 08.10.2026**. Основа — АР от 02.10.2026, ТХ от 07.10.2026 и исходная предварительная модель КМ R01.

## Что можно сделать

- Вращать здание, приближать детали, смотреть сверху в ортографическом режиме.
- Пройти внутри с помощью WASD / стрелок; на сенсорном экране — джойстик и поворот камеры пальцем. Стены, открытые дверные полотна и основные габариты блокируют проход.
- Включать и отключать разделы целиком или их части, включая отдельные поверхности стен и кровли.
- Сделать горизонтальный срез, выбрать помещение или элемент и прочитать его карточку.
- Сохранить PNG шириной от 1920 px, открыть полный экран и скачать GLB.

## Известные вопросы

Кровля в архитектуре имеет уклон **3°**. Исходный каркас КМ R01 имеет **5°** и сохранён отдельным, изначально отключённым слоем. Это предварительный каркас, требующий согласования с архитектурой.

В новом ТХ отмечены: К5 — два шкафа на плане и один в спецификации; D12 — 0,1 кВт в задании подключений и 0,01 кВт в спецификации. Для кипятильника D22 не найдено однозначное место на плане: его размещение требует уточнения.

Неуказанные высоты мебели и оборудования приняты условно по согласованию с заказчиком. Такие элементы помечены в карточках. Отделка нейтральная. Инженерные разделы пока содержат точки подключения из ТХ; трассы сетей будут добавлены после проектирования. Проверка решений выполняется по чертежам, автоматический поиск коллизий в просмотрщике не реализован.

## Файлы модели

- `model/canonical.json` — единая модель с геометрией в метрах, стабильными идентификаторами, слоями, источниками и статусами.
- `assets/cafe.glb` — экспорт всех слоёв для просмотрщика. Внешние GLB-программы могут показывать все слои сразу, включая исходный КМ R01.
- `scripts/build.mjs` — воспроизводимый экспорт GLB и подготовка локального браузерного Three.js.
- `scripts/validate.mjs` — проверка исходных размеров, площадей, проёмов, столкновений и независимая загрузка GLB.
- [Паспорт модели](docs/MODEL_PASSPORT.md), [обновление модели](docs/UPDATE_GUIDE.md).

Исходные DWG/PDF, внутренние документы и обработанные выгрузки остаются локально. В репозитории находятся только код, модель и описание. Учётные записи и серверное хранение для просмотра не требуются.

## Локальная сборка

Node.js 22 или новее, pnpm 11:

```sh
pnpm install --frozen-lockfile --ignore-scripts
pnpm build
pnpm validate
pnpm start
```

Для воспроизведения браузер использует включённую в репозиторий версию Three.js 0.180.0; внешние CDN не нужны. Лицензия библиотеки: `vendor/THREE-LICENSE.txt`.

GitHub Pages публикует ветку `main`, корневой каталог. После изменения модели сначала выполняются сборка, проверка и осмотр в браузере; затем обновляются согласованные публичные файлы в `main`.
