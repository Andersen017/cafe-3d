# Кафе / проект в 3D

Интерактивная модель здания, навеса, террасы, помещений и оборудования. Разделы и поверхности управляются отдельными слоями. Обзор, план, срез и прогулка позволяют осматривать текущие проектные решения.

**Локальная версия R02, 09.10.2026.** Основа: АР 02.10, ТХ 08.10 и заводской каркас ЛСТК 09.10. ЛСТК — основной вариант и основание высот. КМ R01 сохранён как предварительная альтернатива.

## Варианты и слои

Переключатель «ЛСТК / КМ» выбирает связанный комплект каркаса, стен и кровли. Отключение видимости отдельного слоя не меняет выбранную комплектацию и физические препятствия прогулки. Два каркаса одновременно не включаются. «Каркас» показывает конструкции выбранного варианта без архитектурных ограждений и оборудования.

В ЛСТК перенесены все 453 185 граней исходной заводской модели, масштаб 1:1. Основная кровля имеет уклон 3°, навес — 5°. КМ содержит 280 исходных стержней, его кровля — 5°. Геометрия этих стержней сохранена. КМ остаётся предварительной моделью, не рабочей документацией для строительства или закупки.

## Технология и мебель

Каталог содержит 47 позиций. Выбор размещённого предмета открывает его карточку и приближает модель. Бойлер D22 размещён по ТХ 08.10. Вторые весы D12, водоумягчитель к D19 и магнитный держатель находятся в каталоге без размещения.

Модели оборудования упрощены по спецификации: витрины, кофемашина, кофемолка, холодильные столы, мойки и другие предметы. Угловые витрины и столешницы используют контуры плана. Стулья воспроизводят повороты и зеркальные отражения CAD-блоков; кресла и круглые столики террасы — расстановку составных блоков ТХ. Отсутствующие высоты помечены «условно».

Тёплый контур ЛСТК и нейтральная отделка пока показаны условно. Состав утепления, звукоизоляции, обшивок и покрытия будет уточнён по смете. Инженерные слои содержат точки подключений; трассы добавятся после проектирования. Модель служит визуализации и самоконтролю, проверка решений выполняется по чертежам.

## Доступ

R02 подготовлена локально и не опубликована. Требуемая схема: приватный репозиторий и серверная защита просмотрщика по пересылаемой секретной ссылке. Пересылка такой ссылки даёт доступ её получателю. Существующий GitHub Pages с R01 публичен и не обеспечивает эту схему. Перед отправкой R02 в GitHub необходимо завершить настройку закрытого доступа.

Исходные DWG, SAT, PDF, сметы и внутренние документы остаются локально. В комплект входят только код просмотрщика, производная веб-геометрия и описание; `.work` и исходные форматы исключены из Git.

## Файлы и сборка

- `model/canonical.json` — геометрия, слои, источники, варианты, каталог и постоянные идентификаторы.
- `model/lstk-mesh.bin` — производная геометрия заводского каркаса, без исходных документов.
- `assets/cafe.glb` — веб-модель. Внешние программы могут показать оба варианта сразу; в просмотрщике действует переключатель.
- `scripts/build.mjs` — воспроизводимая сборка GLB из включённых данных.
- `scripts/validate.mjs` — контроль исходных размеров, неизменности КМ, граней ЛСТК, вариантов, каталога, направлений мебели и проходов.
- [Паспорт модели](docs/MODEL_PASSPORT.md), [обновление модели](docs/UPDATE_GUIDE.md).

Node.js 22 или новее, pnpm 11:

```sh
pnpm install --frozen-lockfile --ignore-scripts
pnpm build
pnpm validate
pnpm start
```

Превью: `http://localhost:4173`. Сервер слушает только локальный адрес. Three.js 0.180.0 включён в комплект, внешние CDN не используются. Лицензия: `vendor/THREE-LICENSE.txt`.
